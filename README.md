# Nipah


Эмулятор повершелл для виндовс

## Возможности

ИИ котик который вам поможет в ошибках нууу или просто милый котик
панель виджетов
и красивый интерфейс

## Как запустить

1 вариант
скачивайте исходный код
запускаете nipah.bat
2 вариант 
в терминале cd диск:\папка с nipah
потом npm start
