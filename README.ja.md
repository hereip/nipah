# Nipah

**Windows向けの高いカスタマイズ性を備えたターミナルエミュレーター。**

Nipahは、Windows 11のビジュアルデザインをベースに、幅広いカスタマイズ機能を目指す、Windows向けの新しいターミナルのコンセプトです。

使い慣れた快適なインターフェース、本格的なターミナル機能、遊び心のある要素、そして自分好みのアプリに仕上げるための設定機能を組み合わせることを目標としています。

> **プロジェクトの状態：** コンセプト段階・開発開始前。Nipahはまだ日常的に使用できる状態ではありません。以下に記載されている機能は実装済みではなく、今後の予定やアイデアです。

## ビジョン

Nipahは、単に配色を変更しただけのターミナルを目指しているわけではありません。さまざまな作業スタイルや個人の好みに合わせられる、柔軟な作業環境を目指しています。

デザインはWindows 11とFluent Designから着想を得ています。

- 角丸のUIと使いやすさを考えた余白。
- MicaやAcrylicをイメージした任意の視覚効果。
- 滑らかでカスタマイズ可能なアニメーション。
- ライトテーマとダークテーマ。
- ユーザーが自由に設定できるアクセントカラーとカラーパレット。

シンプルな設定でも細かくカスタマイズした状態でも、見やすく快適に使えるインターフェースを目指します。

## 予定している機能

このセクションに記載されている機能はすべて現在のコンセプトに基づくものであり、開発中に変更される可能性があります。

### ターミナル

- コマンド実行を模倣するのではなく、実際のシェルセッションを起動。
- メインのシェルとしてPowerShellに対応。
- 複数のターミナルタブ。
- カスタマイズ可能なターミナルプロファイル。
- 将来的にほかのシェルを追加できる設計。

### 詳細なカスタマイズ

- 色やカラーパレットの自由な設定。
- フォントの種類、サイズ、テキスト表示の設定。
- カーソルのスタイルと動作の設定。
- 背景色や画像の設定。
- 透明度と視覚効果。
- アニメーションのカスタマイズ。
- パネルとレイアウトの変更。
- テーマや設定プリセットのインポート・エクスポート。

### Friendly Errors

PowerShellのエラー表示は、威圧的に見えたり、内容を理解しにくかったりすることがあります。Nipahでは、よくあるエラーを別の見やすい形式で表示する機能を検討しています。

想定しているモード：

- **Original** — シェル本来の出力をそのまま表示。
- **Friendly** — エラーをより分かりやすい言葉で説明。
- **Funny** — ユーモアのあるメッセージや、キャラクターによるリアクションを表示。

元のエラー情報にはいつでもアクセスできるようにする必要があります。表示方法を変更しても、PowerShellのコマンド実行、終了コード、元の診断情報を変更してはいけません。

### Nipah Pets

ターミナルでの操作に反応する、任意で利用できるコンパニオン機能です。

構想している内容：

- キャラクターのアニメーションやさまざまな表情。
- コマンド、処理の成功、エラー、待機状態へのリアクション。
- 定型メッセージを使用するオフラインモード。
- AIでリアクションを生成するオプションモード。
- キャラクター、見た目、リアクション頻度のカスタマイズ。

キャラクター案のひとつは、*Half-Life 2*の世界観に着想を得た、ちびキャラのCivil Protection隊員です。

### シークレットテーマとイースターエッグ

特別なコマンドで有効になる隠しテーマを追加する可能性があります。

現在の案には、Combineをイメージしたインターフェーステーマに切り替える`freeman`イースターエッグがあります。警告やエラー表示もテーマに合わせたデザインになります。`normal`コマンドで通常の外観に戻せるようにする予定です。

これらは任意のビジュアル要素であり、通常のシェルコマンドの実行を妨げてはいけません。

## 設計方針

1. **カスタマイズを重視。** ユーザーが自分の好みに合わせてインターフェースを変更できること。
2. **本物のターミナル動作。** コマンドプロンプトを模倣するのではなく、実際のシェルプロセスを実行すること。
3. **分かりやすさ。** エラー表示を変更しても、元の診断情報を確認できること。
4. **追加機能は任意。** ペット、AIリアクション、視覚効果などは設定で変更・無効化できること。
5. **ユーザー主体。** テーマや外観設定を簡単に保存、共有、復元できること。

## 技術方針

Windows版で現在検討している技術構成：

- **C#とWinUI 3** — Windowsネイティブアプリケーション。
- **Windows Pseudo Console (ConPTY)** — 実際のターミナルプロセスの実行。
- **WebView2とxterm.js** — ターミナル表示レイヤーの候補。

これは調査のための出発点であり、最終的な実装方針ではありません。
